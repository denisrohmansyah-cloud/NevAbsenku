NEV Absenku V14.9.3 — PATCH BACKEND AKUN STAF

Tujuan patch:
1. HRD dapat mengubah Username/NIM staf.
2. HRD dapat mengubah divisi staf.
3. Nama staf dan password juga tetap dapat diubah.
4. Username/NIM harus unik.
5. Tidak perlu mengganti seluruh Code.gs aktif.

PENTING:
Jika deployment aktif Anda sudah menggunakan secure-v6-fast-login, jangan mengganti seluruh Code.gs dengan file lama. Ganti hanya fungsi createUser_ dan updateUser_ seperti di bawah.

============================================================
1. FUNGSI createUser_
============================================================

function createUser_(actor, data){
  if(actor.role!=="HRD" && actor.role!=="KOOR KP") throw new Error("Hanya HRD atau Koor KP yang dapat membuat akun.");

  const name=String(data.name||"").trim();
  const username=String(data.username||"").trim();
  const password=String(data.password||"");
  let division=String(data.division||"").trim();
  let role=String(data.role||"STAF").trim().toUpperCase();

  if(!name || !username || !password) throw new Error("Nama, username, dan password wajib diisi.");

  if(!["STAF","HRD","KOOR KP"].includes(role)){
    throw new Error("Role tidak valid.");
  }

  // Koor KP hanya boleh membuat akun STAF di divisinya sendiri.
  if(actor.role==="KOOR KP"){
    role="STAF";
    division=actor.division;
  }

  // HRD boleh membuat semua role.
  if(role==="HRD"){
    division="";
  }else if(!division){
    throw new Error("Divisi wajib diisi untuk akun STAF atau KOOR KP.");
  }

  const users=sheetToObjects_(SHEET_USERS);
  if(users.some(u=>String(u.username).toLowerCase()===username.toLowerCase())){
    throw new Error("NIM/username sudah digunakan.");
  }

  const record={
    id:"U-"+Date.now()+"-"+Math.floor(Math.random()*10000),
    name,
    username,
    password:hashPassword_(password),
    role,
    division:division || null
  };

  appendObject_(SHEET_USERS,record);
  return safeUser_(record);
}

2. GANTI FUNGSI updateUser_ DENGAN VERSI INI
============================================================

function updateUser_(actor,data){
  const targetId=String(data.targetId||"");
  const users=migratePlaintextPasswords_();
  const user=users.find(u=>u.id===targetId);
  if(!user) throw new Error("Akun tidak ditemukan.");

  if(actor.role==="KOOR KP"){
    if(user.id!==actor.id && (user.role!=="STAF" || user.division!==actor.division)){
      throw new Error("Koor KP hanya dapat mengedit STAF di divisinya.");
    }
  }else if(actor.role!=="HRD"){
    if(user.id!==actor.id) throw new Error("Akses ditolak.");
  }

  if(data.name!==undefined && String(data.name).trim()){
    user.name=String(data.name).trim();
  }

  // Hanya HRD yang boleh mengubah Username/NIM dan divisi STAF.
  if(actor.role==="HRD" && user.role==="STAF"){
    if(data.username!==undefined){
      const newUsername=String(data.username||"").trim();
      if(!newUsername) throw new Error("Username/NIM tidak boleh kosong.");

      const duplicate=users.some(u=>
        u.id!==user.id &&
        String(u.username||"").trim().toLowerCase()===newUsername.toLowerCase()
      );
      if(duplicate) throw new Error("NIM/username sudah digunakan oleh akun lain.");

      user.username=newUsername;
    }

    if(data.division!==undefined){
      const newDivision=String(data.division||"").trim();
      if(!newDivision) throw new Error("Divisi wajib diisi untuk akun STAF.");
      user.division=newDivision;
    }
  }

  if(data.password) user.password=hashPassword_(String(data.password));

  objectsToSheet_(SHEET_USERS,users);
  return safeUser_(user);
}

3. CARA DEPLOY
============================================================

1. Buka Google Apps Script deployment aktif NEV Absenku.
2. Cari createUser_ dan updateUser_.
3. Ganti kedua fungsi tersebut dengan versi di atas.
4. Save.
5. Deploy → Manage deployments.
6. Edit deployment aktif.
7. Version → New version.
8. Deploy.
9. Pastikan Execute as = Me.
10. Pastikan Who has access = Anyone.

Setelah itu:
HRD → Manajemen Akun → pilih staf → tombol pensil.

Form Edit Akun STAF akan menampilkan:
- Nama Lengkap
- Username / NIM
- Divisi
- Password Baru (opsional)

Role STAF tidak dapat diubah melalui form ini.
