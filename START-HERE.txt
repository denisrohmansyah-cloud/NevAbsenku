NEV ABSENKU - FIX GOOGLE SHEETS

Masalah yang terlihat:
"Gagal terhubung ke Google Sheets. Sementara memakai data lokal (offline)."

PENTING: JANGAN campur file lama cloud-sync(1).js + Code(1).gs dengan file v3.
Gunakan seluruh file dalam folder ini sebagai satu paket.

1. Apps Script:
   - Buka Spreadsheet NEV Absenku.
   - Extensions > Apps Script.
   - Hapus kode lama.
   - Tempel SELURUH isi Code.gs dari folder ini.
   - Save.
   - Deploy > Manage deployments > Edit deployment.
   - Version: New version.
   - Execute as: Me.
   - Who has access: Anyone.
   - Deploy.

2. Frontend:
   Upload bersama-sama:
   index.html
   cloud-sync.js
   geo-selfie.js
   geo-selfie.css
   nev-logo.png

3. cloud-sync.js harus menggunakan URL Web App /exec dari deployment yang sama.
   Saat ini file sudah berisi URL yang dipakai pada paket sebelumnya.
   Jika URL deployment berubah, ganti CLOUD_SCRIPT_URL.

4. Setelah upload, buka situs dengan Ctrl+Shift+R.

5. Login ulang.

6. Indikator yang benar setelah login:
   "Tersinkron ..." berwarna hijau.

Jika indikator mengatakan:
"Code.gs di server masih versi lama"
berarti Apps Script belum di-deploy sebagai New version.

JANGAN menggunakan cloud-sync(1).js / Code(1).gs dari paket lama karena format backend-nya berbeda.
